Tomar decisiones: if, else if, else

Hasta ahora el código se ejecutaba completo, de arriba abajo. Con if el programa elige qué parte ejecutar según una condición que da true o false. Con los bucles repite una parte las veces que haga falta.

Truthy y falsy

En un if cualquier valor se convierte a booleano. Solo estos valores cuentan como falsos; todo lo demás (incluidos "0", " " y -5) es verdadero.

Valor falsyCuándo aparece
falseuna condición que no se cumple
0, -0, 0nun contador o un total en cero
""un campo de texto vacío
nullun valor vacío a propósito
undefineduna variable sin valor
NaNuna conversión a número que falló

Bucles: repetir

BucleCuándo usarlo
for (let i = 1; i <= 10; i++)sabes cuántas vueltas: del 1 al 10, 12 meses, 7 días
while (condición)no sabes cuántas: «hasta llegar a la meta»
do { } while (condición)igual que while, pero la primera vuelta siempre se ejecuta
for (const letra of texto)recorrer cada carácter de un texto (y luego de una lista)
breaksale del bucle de inmediato
continuesalta a la siguiente vuelta

Ejemplo 13

Adivina el número (do…while y prompt)

do…while pregunta al menos una vez y repite hasta acertar. prompt() devuelve texto (o null si pulsas Cancelar), por eso lo convertimos con Number y salimos con break si la persona se rinde.

Mientras la ventana de prompt está abierta la página se congela; por eso el historial de intentos aparece en el panel al terminar el juego.

Para invertir un texto vamos poniendo cada letra delante de las anteriores. Si la frase limpia se lee igual al revés, es un palíndromo.

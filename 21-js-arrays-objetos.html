21. JavaScript: arrays y objetos

Casi todos los datos de una aplicación real son listas (productos, mensajes, canciones) o fichas con varios datos (un usuario, un pedido). En JavaScript las listas son arrays y las fichas son objetos. Vas a armar carritos de compras, catálogos filtrados, rankings, estadísticas de notas, una tabla de la liga y a convertir todo a JSON para enviarlo a un servidor. Arrays y objetos de un vistazo

Un array es una lista ordenada: se accede por posición (lista[0]). Un objeto es una ficha con datos con nombre: se accede por clave (usuario.nombre). Lo más común en una app es combinarlos: un array de objetos.

Ejemplo 1

Crear un array: lista de compras

Un array se escribe entre corchetes. Cada elemento tiene un índice que empieza en 0. length dice cuántos hay y at(-1) da el último. Aunque el array sea const, su contenido se puede cambiar.

Ejemplo 2

Agregar y quitar: la fila de turnos

push agrega al final y pop quita el último. unshift agrega al inicio y shift quita el primero. Los cuatro modifican el array original.

Ejemplo 3

slice, splice, join y spread: editar una playlist

slice(inicio, fin) copia un tramo sin tocar el original. splice(posición, cuántos, ...nuevos) quita o inserta en el original. join une todo en un texto y ... (spread) despliega un array dentro de otro.

Ejemplo 4

Buscar y quitar duplicados: lista de invitados

includes responde sí o no; indexOf da la posición o -1 si no está. Un Set es una colección que no admite repetidos: ideal para un carrito sin duplicados.

Ejemplo 5

Recorrer un array: tareas y duración de una playlist

for…of recorre cada elemento. forEach hace lo mismo con una función flecha (un callback) y además entrega el índice.

Ejemplo 6

Objetos: la ficha de un producto

Un objeto guarda datos con nombre (propiedades) entre llaves. Se leen con punto o con corchetes (cuando el nombre está en una variable o tiene espacios). Una función dentro de un objeto es un método y con this lee las propiedades de su propio objeto.

Ejemplo 7

Desestructuración: perfil de usuario

La desestructuración saca propiedades a variables en una sola línea. Permite renombrar (edad: edadUsuario), poner valores por defecto, entrar en objetos anidados y usarla directamente en los parámetros de una función.

Ejemplo 8

Object.keys, values y entries: ficha técnica

Estos tres métodos convierten un objeto en arrays: las claves, los valores o pares [clave, valor]. Con entries y for…of se recorre un objeto completo, y padEnd alinea el texto como una tabla.

Ejemplo 9

Spread en objetos: configuración con valores por defecto

{ ...a, ...b } copia las propiedades de a y luego las de b; si se repiten, gana la última. Así se combinan las preferencias del usuario con la configuración por defecto. Con shorthand, { nombre } equivale a { nombre: nombre }.

Ejemplo 10

map: transformar un catálogo

map crea un array nuevo del mismo tamaño, con lo que devuelve el callback para cada elemento. Para devolver un objeto desde una flecha corta se envuelve en paréntesis: (p) => ({ ... }).

Ejemplo 11

filter: catálogo por categoría y stock bajo

filter devuelve un array nuevo solo con los elementos para los que el callback devuelve true. Se puede encadenar con map para quedarse solo con los nombres.

Ejemplo 12

find y findIndex: buscador de contactos

find devuelve el primer elemento que cumple la condición (o undefined); findIndex devuelve su posición (o -1). Para un buscador que muestre todas las coincidencias se usa filter.

Ejemplo 13

some y every: lista de tareas

some responde si al menos uno cumple la condición; every, si la cumplen todos. Junto con filter resuelven el típico panel de pendientes y completadas.

Ejemplo 14

reduce: subtotal del carrito y ventas por mes

reduce recorre el array acumulando un resultado. El callback recibe el acumulado y el elemento actual, y lo que devuelve pasa a ser el nuevo acumulado. El segundo argumento es el valor inicial: 0 para sumar, {} para agrupar.

Ejemplo 15

Estadísticas de notas: promedio, máxima y mínima

Con reduce se suma, con Math.max(...notas) el spread pasa cada nota como argumento, y con filter se cuentan los aprobados. reduce también encuentra el objeto con la nota más alta.

Ejemplo 16

sort y toSorted: ranking y top 3 más vendidos

Sin comparador, sort ordena como texto (¡100 antes que 25!). Con (a, b) => a - b ordena números y con localeCompare ordena textos con tildes. sort modifica el original; toSorted devuelve una copia ordenada.

Ejemplo 17

Tabla de posiciones de una liga

Todo junto: map calcula puntos y diferencia de goles, toSorted ordena por puntos y desempata por diferencia, y padEnd dibuja la tabla en columnas.

Ejemplo 18

JSON: convertir un pedido para enviarlo

JSON es el formato de texto con el que viajan los datos entre el navegador y un servidor. JSON.stringify convierte objetos y arrays en texto; JSON.parse hace lo contrario. Los métodos y los valores undefined no se guardan.

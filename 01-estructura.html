Anatomía de un elemento

<etiqueta atributo="valor">contenido</etiqueta>
 \_____/ \______________/ \_______/ \_________/
 apertura    atributo     contenido   cierre

<!DOCTYPE html> declara que el documento usa HTML moderno. El elemento <html> contiene la página y su atributo lang indica el idioma. <head> guarda metadatos y el título de la pestaña; <body> contiene lo que se muestra. <meta charset="UTF-8"> permite usar correctamente caracteres como ñ y tildes.

Ejemplo 18

Ver el código fuente y validar una página

Cualquier página web se puede inspeccionar. Es la mejor forma de aprender cómo están hechas otras webs y de encontrar errores en la tuya.

Guía rápida para revisar tu página

Paso 1: ver el código fuente

Pulsa Ctrl + U (Windows y Linux) o Cmd + Opción + U (Mac). También: clic derecho → «Ver código fuente de la página».

Paso 2: inspeccionar un elemento

Pulsa F12 o clic derecho sobre cualquier parte → «Inspeccionar». Verás el árbol de elementos y podrás probar cambios en vivo.

Paso 3: validar

Entra en validator.w3.org, elige «Validate by File Upload» o «Validate by Direct Input» y pega tu código. El validador te dirá la línea exacta de cada error.

Ejemplo de mensaje del validador

Error: End tag h3 seen, but there were open elements.
From line 12, column 5; to line 12, column 9

From line 10, column 12; to line 10, column 19

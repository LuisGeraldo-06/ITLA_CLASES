Cómo llega JavaScript a la página

HTML pone el contenido, CSS lo viste y JavaScript le da comportamiento: hace cálculos, toma decisiones y cambia la página. El código se escribe en un archivo .js aparte y se conecta en el <head> con una etiqueta <script>. El atributo defer le dice al navegador: «descárgalo ya, pero ejecútalo cuando termines de leer todo el HTML». Así el script nunca se adelanta a la página.

Variables: let y const

Una variable es una caja con nombre donde guardas un valor. Usa const por defecto y let solo si el valor va a cambiar. var es la forma antigua: ignora los bloques { } y deja usar la variable antes de declararla, así que hoy no se usa.

Palabra¿Se puede reasignar?Cuándo usarla
constNocasi siempre: precios, nombres, resultados de un cálculo
letSícontadores, acumuladores, valores que cambian
varSínunca en código nuevo (la verás en tutoriales viejos)

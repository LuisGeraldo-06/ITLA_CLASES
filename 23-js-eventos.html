23. JavaScript: eventos

En la lección 22 aprendimos a cambiar la página; ahora decidimos cuándo. Un evento es algo que pasa: un clic, una tecla, el mouse que se mueve, la página que se desplaza, la ventana que cambia de tamaño. Con addEventListener le decimos al navegador “cuando pase esto, ejecuta esta función”. Con eso construimos los componentes que se ven en todos los sitios: menú hamburguesa, pestañas, modales, acordeones, carritos y listas de tareas.

Escuchar eventos

Se elige el elemento, el tipo de evento y la función que se ejecutará cada vez que ocurra. El navegador llama a esa función y le pasa un objeto evento con los detalles de lo que pasó.

EventoOcurre cuando…
click / dblclickse hace clic / doble clic (también Enter o Espacio en un botón)
inputcambia el valor de un campo, con cada tecla
changeel valor cambió y se confirmó (select, checkbox, o al salir del campo)
submitse envía un formulario (botón submit o Enter)
keydownse pulsa una tecla (evento.key dice cuál)
mouseenter / mouseleaveel puntero entra / sale del elemento
mousemoveel puntero se mueve encima (muchas veces por segundo)
focus / blurel elemento gana / pierde el foco
scrollse desplaza la ventana o un elemento con scroll
resizecambia el tamaño de la ventana (se escucha en window)
DOMContentLoadedel HTML terminó de leerse (se escucha en document)
Objeto eventoQué contiene o hace
evento.typeel nombre del evento ("click", "keydown"…)
evento.targetel elemento exacto donde ocurrió
evento.currentTargetel elemento que tiene el listener
evento.keyla tecla pulsada: "a", "Enter", "Escape", "ArrowLeft"…
evento.ctrlKey / shiftKey / altKeytrue si esa tecla estaba pulsada
evento.clientX / clientYposición del puntero en la ventana
evento.preventDefault()cancela lo que el navegador haría solo (enviar el formulario, seguir el enlace)
evento.stopPropagation()impide que el evento siga subiendo a los padres

Si el script lleva defer (como en este curso), ya se ejecuta con el HTML completo y no necesitas DOMContentLoaded. Ese evento es útil cuando el script está en el <head> sin defer, algo que verás en código antiguo. Y nunca uses onclick="…" dentro del HTML: mezcla contenido y lógica, y solo admite una función por evento.

Atajos de teclado con keydown

Como en los clientes de correo: j y k mueven la selección, e archiva y / lleva al buscador. El listener está en document, así que funciona en toda la página, pero se ignora mientras escribes en un campo.

  • Factura de octubre · Luz Norte
  • Tu pedido llegó · Tienda Nubo
  • Reunión del lunes · Marta
  • Nueva clase disponible · Academia Kiwi

j bajar · k subir · e archivar · / buscar

Última tecla: —

Sin la primera condición, escribir una “e” en el buscador archivaría un correo. preventDefault() con / evita que esa barra se escriba dentro del buscador al recibir el foco. Respetar Ctrl/⌘ deja funcionar los atajos del navegador.

        Una sola vez: { once: true } y removeEventListener

        El regalo de bienvenida se puede reclamar una vez: con { once: true } el listener se borra solo tras el primer clic (pulsa varias veces y los puntos no suben). La tarjeta “raspa y gana” da tres intentos y luego quita su listener con removeEventListener.

        Tienes 0 puntos.

        Te quedan 3 intentos.

        Para quitar un listener hay que pasar la misma función que se usó al ponerlo; por eso raspar tiene nombre. Con una función flecha escrita directamente dentro de addEventListener no habría forma de referirse a ella después.

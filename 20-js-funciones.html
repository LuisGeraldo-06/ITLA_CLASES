20. JavaScript: funciones

Hasta ahora el código corría de arriba abajo una sola vez. Una función es un bloque de código con nombre que se escribe una vez y se usa todas las veces que haga falta, con datos distintos cada vez. Vas a crear formateadores de precios, validadores, generadores de slugs y contraseñas, cupones, contadores con memoria y hasta funciones que se llaman a sí mismas. Todos los ejemplos muestran su resultado en la consola de la página: pulsa Ejecutar.

Cómo se escribe y se usa una función

Una función se define una vez y se llama (se ejecuta) poniendo su nombre seguido de paréntesis. Lo que va entre paréntesis al definirla son los parámetros; lo que se le pasa al llamarla son los argumentos.

FormaEjemploCuándo usarla

Expresiónconst sumar = function (a, b) { return a + b; };cuando la función se guarda como un valor más

Ejemplo 1

Declarar una función: formateador de precios

Con function nombre(parámetros) { … } se declara una función. return entrega el resultado a quien la llamó. Las funciones declaradas así se pueden usar antes de la línea donde aparecen (hoisting).

Ejemplo 2

Expresiones y funciones flecha: impuesto y total

Una función también es un valor: se puede guardar en una constante. La forma más corta es la función flecha =>; si su cuerpo es una sola expresión, el return es implícito.

Ejemplo 3

Parámetros con valor por defecto: mensaje de WhatsApp

Un parámetro puede traer un valor por defecto con =. Se usa cuando el argumento no llega (o llega undefined). Si falta un argumento sin valor por defecto, dentro de la función vale undefined.

Ejemplo 4

return: convertidor de unidades

return devuelve un valor que se puede guardar, imprimir o pasar a otra función. Una función sin return devuelve undefined.

Ejemplo 5

Return temprano: validador de correo

Cada return termina la función en ese instante. Revisar los errores primero y salir con return evita if anidados: el caso feliz queda al final.

Ejemplo 6

Saludo según la hora del día

Una función que recibe un número y decide qué texto devolver. Con new Date().getHours() se obtiene la hora actual de la computadora (0 a 23).

Ejemplo 7

Scope: qué variables ve cada función

Las variables declaradas dentro de una función (o de un bloque { }) solo existen ahí. Desde adentro sí se ven las de afuera. Si adentro se declara otra con el mismo nombre, la de adentro tapa a la de afuera.

Ejemplo 8

Funciones puras e impuras

Una función pura solo usa sus parámetros y no cambia nada de afuera: con los mismos datos siempre da el mismo resultado. Son fáciles de probar y de reutilizar. Una impura depende o modifica variables externas.

Ejemplo 9

Funciones que llaman a otras: generar una factura

Las funciones pequeñas, cada una con una sola tarea, se combinan para resolver algo más grande. Si cambia la tasa del impuesto, se corrige en un único lugar.

Ejemplo 10

Generador de slugs para URLs

Los blogs y tiendas convierten el título en un slug: minúsculas, sin tildes, sin signos y con guiones. normalize("NFD") separa la tilde de su letra (á → a + ´) para poder descartarla.

Ejemplo 11

Iniciales de un nombre y títulos capitalizados

Dos utilidades de texto que aparecen en cualquier app: las iniciales para el avatar del usuario y el título con cada palabra en mayúscula. Ambas recorren el texto letra por letra recordando la letra anterior.

Ejemplo 12

Generador de contraseñas

Una función auxiliar elige un número al azar y otra arma la contraseña con la longitud y los caracteres pedidos. Se quitaron letras confusas como l, I, O y 0. Para contraseñas reales se usa crypto.getRandomValues, que es más seguro que Math.random.

Ejemplo 13

Calculadora de descuentos por cupón

Una función decide cuánto se descuenta según el cupón (con switch y return en cada caso) y otra arma el mensaje para el cliente usando la primera.

Ejemplo 14

Callbacks: pasar una función como argumento

Como las funciones son valores, se pueden pasar a otra función. La que las recibe decide cuándo llamarlas. Ojo: descuento20 pasa la función; descuento20() la ejecutaría.

Ejemplo 15

Closures: contador de clics privado

Una función creada dentro de otra recuerda las variables de donde nació, aunque la de afuera ya haya terminado. Eso es un closure. Cada contador tiene su propia cuenta y nadie de afuera la puede tocar.

Ejemplo 16

Fábricas de funciones: generador de IDs y convertidores

Una función que devuelve funciones ya configuradas. Cada generador de IDs lleva su propia numeración y cada convertidor recuerda su factor y su unidad.

Ejemplo 17

Parámetros rest: cuántos argumentos quieras

...nombre como último parámetro junta todos los argumentos sobrantes en una lista que se puede recorrer con for…of y que tiene length.

Ejemplo 18

Recursión: factorial y carpetas anidadas

Una función recursiva se llama a sí misma con un problema más pequeño. Siempre necesita un caso base que la detenga; si no, se llamaría para siempre.

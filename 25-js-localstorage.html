Guardar datos en el navegador

Todo lo que hicimos hasta ahora se pierde al recargar la página. localStorage es un pequeño «cajón» de pares clave → valor que el navegador guarda para cada sitio y que sobrevive a recargas, pestañas cerradas y reinicios. Sirve para preferencias, borradores, carritos y listas; no es una base de datos ni un lugar seguro.

Método / propiedadQué hace
localStorage.setItem("clave", valor)guarda (o reemplaza) un valor. Lo convierte a texto
localStorage.getItem("clave")devuelve el texto guardado, o null si la clave no existe
localStorage.removeItem("clave")borra esa clave
localStorage.clear()borra todas las claves del sitio (¡también las de otras páginas del mismo sitio!)
localStorage.length / localStorage.key(i)cuántas claves hay / el nombre de la clave número i
Object.keys(localStorage)un array con todas las claves
JSON.stringify(dato)convierte un objeto o array en texto para poder guardarlo
JSON.parse(texto)convierte ese texto de vuelta en objeto o array
window.addEventListener("storage", …)avisa cuando otra pestaña del mismo sitio cambió algo

Durahasta que se borre (por código o por la persona)hasta cerrar la pestaña
Se comparteentre todas las pestañas del mismo sitiosolo dentro de esa pestaña
Métodoslos mismos: setItem, getItem, removeItem, clear
Espaciounos 5 MB por sitio. Si se llena, setItem lanza QuotaExceededError

Todas las claves de esta lección empiezan con curso- para no chocar con otras páginas. Si abres las lecciones como archivos (file://), el navegador puede tratar a todas como el mismo sitio y compartir el mismo localStorage: por eso los nombres de clave deben ser únicos. El ejemplo 18 te deja ver y borrar todo lo que guardó el curso.

Ejemplo 2

Objetos y arrays: JSON.stringify y JSON.parse

Si guardas un objeto tal cual, se guarda el texto inútil "[object Object]". Hay que convertirlo a texto JSON al guardar y volver a convertirlo al leer. Ejecuta varias veces y recarga la página para comprobarlo: la lista de cursos sigue creciendo porque cada vez se lee lo guardado, se agrega uno y se vuelve a guardar.

El ciclo es siempre el mismo: leer → JSON.parse → modificar → JSON.stringify → guardar. Modificar el objeto en memoria no cambia nada en localStorage hasta que vuelves a llamar a setItem.

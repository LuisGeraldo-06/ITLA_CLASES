04. Tablas

Las tablas organizan datos relacionados en filas y columnas: facturas, horarios, calendarios, resultados deportivos, comparativas de precios. Si los datos tienen sentido en una hoja de cálculo, probablemente van en una tabla.

Elementos de la tabla

Una tabla se construye fila por fila: cada tr es una fila y dentro van sus celdas. Las columnas no se escriben: aparecen solas al alinear las celdas de todas las filas.

Etiqueta / atributoPara qué sirve
tablecrea la tabla
captiontítulo de la tabla; va justo después de <table>
thead, tbody, tfootagrupan filas de encabezado, de datos y de totales
truna fila
thcelda de encabezado (negrita y centrada por defecto)
tdcelda de datos
scope="col" / scope="row"indica si el th encabeza una columna o una fila
colspan="n"la celda ocupa n columnas
rowspan="n"la celda ocupa n filas
colgroup / col span="n"agrupan columnas para darles estilo después con CSS
headers + idrelacionan cada celda con sus encabezados en tablas complejas

Usa tablas para datos tabulares, no para organizar el diseño de una página.

Nota: los ejemplos de esta página muestran cómo dibuja el navegador una tabla sin estilos: sin bordes ni colores. El viejo atributo border="1" está obsoleto; los bordes, el relleno y los colores de las celdas se añaden con CSS en lecciones posteriores.

Ejemplo 16

Datos tabulares sí, maquetación no

Hace años las páginas se maquetaban con tablas: una celda para el menú, otra para el contenido. Hoy es una mala práctica: los lectores de pantalla anuncian "tabla de 2 columnas" sin que haya datos, el diseño no se adapta al móvil y el código es difícil de mantener. Para la estructura se usan etiquetas semánticas y CSS.

Mal: una tabla usada para colocar el menú a la izquierda del contenido.

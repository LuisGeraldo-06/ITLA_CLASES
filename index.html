Cómo practicar

  • Abre cada lección en el navegador y compara cada resultado con el código que aparece debajo.
  • Usa el botón Copiar de cada bloque de código para pegarlo en tu propio archivo.
  • Pulsa Ctrl + U para ver el código fuente completo, o F12 para inspeccionar un elemento.
  • Cambia valores en los archivos de css/ y js/, guarda y recarga para ver el efecto.

16. CSS: variables y temas

Las variables CSS (su nombre oficial es custom properties) guardan un valor con un nombre para reutilizarlo en muchos lugares. Cambias el valor en un solo sitio y se actualiza todo: colores de marca, modo oscuro, temas, tamaños y espaciados. Son la base de cualquier sistema de diseño moderno.

Declarar, usar y redefinir

Una variable CSS es una propiedad cuyo nombre empieza con dos guiones. Se declara dentro de una regla, como cualquier otra propiedad, y se lee con la función var(). Igual que color o font-family, se hereda a todos los descendientes.

SintaxisQué hace
--color-marca: #7c3aed;declara la variable
var(--color-marca)usa su valor
var(--color-marca, gray)usa gray si la variable no existe
calc(var(--n) * 1px)convierte un número en una medida
hsl(var(--h) 70% 50%)arma un color a partir de un número
color-mix(in srgb, var(--c) 20%, white)mezcla colores para crear variantes
@property --x { ... }le da un tipo a la variable para poder animarla
Dónde se declaraAlcance
:root { ... }toda la página (variables globales)
.tarjeta { ... }esa tarjeta y todo lo que tiene dentro
.btn:hover { ... }solo mientras dure ese estado
.app:has(:checked) { ... }cuando se cumple una condición
@media (...) { .x { ... } }solo en ciertas pantallas

Ejemplo 18

Animar variables con @property

Una variable normal es solo texto: el navegador no sabe si es un color o un ángulo, por eso salta de un valor a otro. Con @property se le da un tipo y entonces se puede animar: un borde de degradado que gira, un contador de ventas y un botón cuyo degradado cambia suave.

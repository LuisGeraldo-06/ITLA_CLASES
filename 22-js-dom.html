Qué es el DOM

Cuando el navegador lee el HTML, construye en memoria un árbol de objetos: el Document Object Model. Cada etiqueta es un nodo con padre, hijos y hermanos. JavaScript no edita el archivo HTML: edita ese árbol, y el navegador vuelve a pintar la página al instante.

Buscar elementosDevuelve
document.getElementById("menu")el elemento con ese id, o null
document.querySelector(".tarjeta")el primer elemento que cumple el selector CSS, o null
document.querySelectorAll("li")todos los que cumplen (una NodeList con forEach y length)
elemento.querySelector(...)busca solo dentro de ese elemento
elemento.closest(".pedido")el ancestro más cercano (o él mismo) que cumple el selector
Leer y cambiarPara qué sirve
textContentel texto puro; lo que asignas se muestra tal cual (seguro)
innerHTMLel HTML de dentro; lo que asignas se interpreta como etiquetas (cuidado con datos del usuario)
classList.add / remove / toggle / containsponer, quitar, alternar o consultar clases
style.width = "40%"estilo en línea; propiedades en camelCase (backgroundColor)
getAttribute / setAttribute / removeAttribute / hasAttributecualquier atributo HTML
img.src, a.href, input.value, boton.disabledatajos para los atributos más comunes
dataset.preciolee y escribe atributos data-precio
Crear, mover y eliminarQué hace
document.createElement("li")crea un elemento nuevo, todavía fuera de la página
padre.append(a, b) / padre.prepend(a)lo mete al final / al principio del padre
elemento.before(x) / elemento.after(x)lo coloca como hermano anterior / siguiente
elemento.remove()lo quita de la página
padre.replaceChildren()vacía el padre (o lo reemplaza por lo que le pases)
plantilla.content.cloneNode(true)copia el contenido de un <template>
Recorrer el árbolLleva a…
parentElementel padre
childrenlos hijos que son elementos
firstElementChild / lastElementChildel primer / último hijo
nextElementSibling / previousElementSiblingel hermano siguiente / anterior

Con defer el script se descarga en paralelo y se ejecuta cuando el HTML ya está completo, así que querySelector siempre encuentra los elementos. Sin defer y en el <head>, el script correría antes de que existan y obtendrías null.

Ejemplo 3

textContent vs innerHTML (y el riesgo XSS)

Imagina que un usuario escribe un comentario con etiquetas HTML. Con textContent se ve como texto; con innerHTML el navegador lo interpreta. Ese es el origen de los ataques XSS.

Con textContent

Con innerHTML

innerHTML con HTML propio

Aquí solo cambia un color, pero un atacante podría escribir <img src="x" onerror="…"> y ejecutar su propio JavaScript en la página de otra persona (robar la sesión, por ejemplo). Regla práctica: datos que escribe el usuario → textContent; innerHTML solo con HTML que escribiste tú.

Ejemplo 4

Insignias de stock con classList según la cantidad

El HTML trae solo números. JavaScript los lee, decide y pone la clase que corresponde: agotado, pocas o disponible. El CSS se encarga del color.

  • Audífonos Sonar 12
  • Teclado Kappa 3
  • Mouse Orbe 0
  • Monitor Vista 1

classList no borra las clases que ya tenía el elemento, a diferencia de className = "…", que las reemplaza todas. contains responde true o false.

Ver ejemplo completo

Copia este código en un archivo nuevo .html y ábrelo en el navegador: se verá igual que el resultado de arriba.

<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Insignias de stock con classList según la cantidad</title>
    <style>
        * {
            box-sizing: border-box;
        }

        body {
            margin: 24px;
            font-family: system-ui, -apple-system, "Segoe UI", Roboto, sans-serif;
            line-height: 1.6;
            color: #1f2430;
        }

        img {
            max-width: 100%;
            height: auto;
        }

        button {
            font: inherit;
        }

        .inventario {
            display: grid;
            gap: 8px;
            padding: 0;
            list-style: none;
        }

        .inventario li {
            display: flex;
            justify-content: space-between;
            padding: 10px 14px;
            border: 1px solid #dfe3ec;
            border-radius: 8px;
        }

        .insignia {
            padding: 2px 10px;
            border-radius: 999px;
            font-size: 0.8rem;
            font-weight: 700;
        }

        .disponible {
            background: #dcfce7;
            color: #166534;
        }

        .pocas {
            background: #fef3c7;
            color: #92400e;
        }

        .agotado {
            background: #fee2e2;
            color: #991b1b;
        }

        .sin-stock {
            opacity: 0.55;
            text-decoration: line-through;
        }
    </style>
</head>
<body>
    <ul class="inventario">
        <li>Audífonos Sonar <span class="insignia">12</span></li>
        <li>Teclado Kappa <span class="insignia">3</span></li>
        <li>Mouse Orbe <span class="insignia">0</span></li>
        <li>Monitor Vista <span class="insignia">1</span></li>
    </ul>
    <script>
        const insignias = document.querySelectorAll(".insignia");

        insignias.forEach((insignia) => {
            const cantidad = Number(insignia.textContent);

            if (cantidad === 0) {
                insignia.classList.add("agotado");
                insignia.textContent = "Agotado";
            } else if (cantidad <= 3) {
                insignia.classList.add("pocas");
                insignia.textContent = `¡Últimas ${cantidad}!`;
            } else {
                insignia.classList.add("disponible");
                insignia.textContent = `${cantidad} disponibles`;
            }

            if (insignia.classList.contains("agotado")) {
                insignia.parentElement.classList.add("sin-stock");
            }
        });
    </script>
</body>
</html>

Ejemplo 6

Barra de progreso con style.width

Cuando el valor sale de un cálculo (un porcentaje, una posición), se usa style. Cuando es un estado (completo, activo, error), se usa una clase.

Curso de JavaScript ·

toggle("completo", condicion) recibe un segundo argumento: si es true pone la clase y si es false la quita. Evita escribir un if con add y remove. Las propiedades de style van en camelCase: style.backgroundColor, style.fontSize.

Copia este código en un archivo nuevo .html y ábrelo en el navegador: se verá igual que el resultado de arriba.

        const total = 10;

            completadas++;
            actualizar();
        });
    </script>

        Breadcrumbs (migas de pan) generados desde la ruta

        A partir de una ruta como /tienda/hogar/cocina/… se construye la navegación “Inicio › Tienda › Hogar…”. El último nivel no es enlace: es la página actual.

        1. Inicio

        Ruta:

        En un sitio real la ruta saldría de location.pathname, que contiene la ruta de la página actual. Los separadores “›” los pone el CSS con li + li::before, no JavaScript.

        Ver ejemplo completo

        Copia este código en un archivo nuevo .html y ábrelo en el navegador: se verá igual que el resultado de arriba.

        <!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Breadcrumbs (migas de pan) generados desde la ruta</title>
    <style>
        * {
            box-sizing: border-box;
        }

        body {
            margin: 24px;
            font-family: system-ui, -apple-system, "Segoe UI", Roboto, sans-serif;
            line-height: 1.6;
            color: #1f2430;
        }

        img {
            max-width: 100%;
            height: auto;
        }

        button {
            font: inherit;
        }

        .migas ol {
            display: flex;
            flex-wrap: wrap;
            margin: 0;
            padding: 0;
            list-style: none;
        }

        .migas li + li::before {
            content: "›";
            margin: 0 8px;
            color: #94a3b8;
        }

        .migas a {
            color: #2563eb;
        }

        .migas [aria-current="page"] {
            color: #5b6275;
            font-weight: 700;
        }
    </style>
</head>
<body>
    <nav class="migas" aria-label="Ruta de navegación">
        <ol id="migas">
            <li><a href="/">Inicio</a></li>
        </ol>
    </nav>
    <p>Ruta: <code id="ruta-actual"></code></p>
    <script>
        const ruta = "/tienda/hogar/cocina/sartenes-antiadherentes";
        const partes = ruta.split("/").filter((parte) => parte !== "");
        const migas = document.querySelector("#migas");
        let acumulado = "";

        document.querySelector("#ruta-actual").textContent = ruta;

        partes.forEach((parte, indice) => {
            acumulado += `/${parte}`;
            const texto = parte.replaceAll("-", " ");
            const nombre = texto[0].toUpperCase() + texto.slice(1);
            const item = document.createElement("li");

            if (indice === partes.length - 1) {
                const actual = document.createElement("span");
                actual.textContent = nombre;
                actual.setAttribute("aria-current", "page");
                item.append(actual);
            } else {
                const enlace = document.createElement("a");
                enlace.href = acumulado;
                enlace.textContent = nombre;
                item.append(enlace);
            }

            migas.append(item);
        });
    </script>
</body>
</html>

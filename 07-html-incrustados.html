07. Imágenes y contenido incrustado

Una página puede mostrar imágenes propias o de otros sitios, adaptarlas a cada pantalla, dibujar gráficos con SVG e incrustar páginas completas como videos, mapas o documentos PDF.

Elementos de esta lección

Todas las imágenes deben llevar alt (texto alternativo) y conviene indicar width y height para que la página no "salte" mientras cargan.

Ejemplo 2

Imagen con enlace: galería de miniaturas

Una imagen dentro de <a> funciona como botón. Al hacer clic en cada miniatura se abre la foto completa en otra pestaña, como en un portal inmobiliario.

Ejemplo 3

Carga diferida: catálogo de productos

loading="lazy" le dice al navegador que descargue la imagen solo cuando el usuario se acerque a ella. Ideal para catálogos largos. Abre las herramientas de desarrollador (pestaña Red) y desplázate para verlo.

Ejemplo 4

Varias resoluciones con srcset y sizes

El navegador elige el archivo más adecuado según el ancho de la pantalla. Un celular descarga la versión pequeña; un monitor grande, la de 1200 px.

Ejemplo 5

srcset por densidad de píxeles: foto de perfil

Las pantallas Retina tienen 2 o 3 píxeles físicos por cada píxel CSS. Con los descriptores 1x, 2x y 3x se entrega una versión más nítida a esas pantallas, manteniendo el mismo tamaño visible.

Camila Ríos · Diseñadora gráfica

Ejemplo 6

Imagen distinta según el tamaño con picture

Achica la ventana del navegador: en pantallas pequeñas aparece un recorte cuadrado y en pantallas grandes una franja horizontal. A esto se le llama "dirección de arte".

Ejemplo 7

picture para formatos modernos: WebP con respaldo JPG

WebP y AVIF pesan mucho menos que JPG. Con type el navegador usa el formato moderno si lo entiende y, si no, cae al img en JPG.

Hostal Los Coihues · desayuno incluido

Ejemplo 8

Figura con pie de foto

figure une la imagen con su leyenda. También puede agrupar varias imágenes bajo un mismo pie, como en un reportaje.

Ejemplo 9

Mapa de imagen: zonas cliqueables sobre una foto

Con map y area se definen zonas de la imagen que funcionan como enlaces. Pasa el mouse por los techos de los tres trulli y por la puerta central: el cursor cambia a una mano.

Ejemplo 10

SVG dentro del HTML: logo, íconos y gráfico de barras

SVG describe dibujos con formas (círculos, rectángulos, líneas, texto). Es vectorial: se ve nítido a cualquier tamaño y pesa muy poco.

Ejemplo 16

Contenido escrito directamente con srcdoc

En vez de una dirección, srcdoc recibe el HTML completo dentro del atributo. Los servicios de correo lo usan para mostrar la vista previa de un email sin que sus estilos afecten al resto de la página.

Vista previa de un correo

Ejemplo 17

Iframe con permisos limitados: sandbox

Con sandbox el contenido del iframe no puede ejecutar scripts, enviar formularios, abrir ventanas ni navegar la página principal. Útil para mostrar contenido que escribió un usuario. Prueba el botón "Enviar": no pasa nada.

Comentario de un usuario, aislado

Ejemplo 18

Documento PDF incrustado con object

object muestra el PDF con el visor del navegador. Si no puede (por ejemplo, en muchos celulares), muestra el contenido de respaldo: un enlace para descargarlo.

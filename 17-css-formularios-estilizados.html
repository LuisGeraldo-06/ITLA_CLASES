Las herramientas para estilizar formularios

Un control de formulario tiene estados (enfocado, marcado, inválido, desactivado…) y partes internas (el texto de ayuda, el botón del archivo, la bolita del slider). Las pseudo-clases eligen el estado y los pseudo-elementos llegan a las partes.

Pseudo-claseSe activa cuando…
:hoverel puntero está encima
:focusel control tiene el foco (clic o teclado)
:focus-visibletiene el foco y el navegador cree que hay que mostrarlo (sobre todo con teclado)
:focus-withinel elemento o algo dentro tiene el foco
:checkedun checkbox o radio está marcado
:disabled / :enabledel control está desactivado o activo
:read-only / [readonly]se puede leer pero no editar
:required / :optionaltiene o no el atributo required
:valid / :invalidcumple o no sus reglas, desde que carga la página
:user-valid / :user-invalidigual, pero solo después de que la persona interactuó
:placeholder-shownel placeholder se está viendo (el campo está vacío)
:has(...)el elemento contiene algo que cumple la condición
Pseudo-elemento / propiedadQué estiliza
::placeholderel texto de ejemplo dentro del campo
::selectionel texto que la persona selecciona
::file-selector-buttonel botón “Elegir archivo”
::-webkit-slider-thumb / ::-moz-range-thumbla bolita del range (Chrome/Safari y Firefox)
appearance: nonequita el dibujo nativo para dibujar uno propio
accent-colorcambia el color de checkbox, radio, range y progress en una línea
caret-colorel color del cursor de texto
field-sizing: contentel campo crece con lo que se escribe

Ejemplo 3

Etiqueta flotante (floating label)

La etiqueta empieza dentro del campo y sube cuando escribes. El truco: un placeholder=" " (un espacio) y :placeholder-shown para saber si el campo está vacío.

Estilo relleno

Estilo contorno

El label sigue siendo un <label> real conectado con for: el lector de pantalla lo anuncia y al hacer clic sobre él se enfoca el campo. pointer-events: none deja que el clic pase al input que está debajo.

Ejemplo 12

Subir archivos: botón y zona de arrastre

El botón “Elegir archivo” se estiliza con ::file-selector-button. Para la zona de arrastre, el input se estira invisible sobre toda la caja: soltar un archivo encima funciona de forma nativa.

📷 Arrastra tus fotos aquí o haz clic para elegirlas · JPG o PNG, hasta 5 MB ✓ Archivos seleccionados

El input es required: vacío es :invalid y con archivos pasa a :valid. Así la zona se pone verde sin JavaScript. Mostrar el nombre de cada archivo o resaltar la zona mientras se arrastra sí necesita JavaScript.

Ejemplo 13

Textarea que crece, cursor y selección

Una caja de comentarios como la de una red social. field-sizing: content hace que el campo crezca mientras escribes; caret-color, ::placeholder y ::selection le dan los detalles finales. Selecciona texto para ver el resaltado.

Tu navegador todavía no soporta field-sizing: los campos tienen tamaño fijo, pero el formulario funciona igual.
